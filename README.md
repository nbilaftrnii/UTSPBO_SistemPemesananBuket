## 📌 Deskripsi Proyek

**Bloom mam** merupakan program **Sistem Pemesanan Buket** berbasis Command Line Interface (CLI) yang dibuat menggunakan bahasa pemrograman **Java**.

Program ini digunakan untuk menampilkan daftar buket, melakukan pemesanan buket, membuat buket custom, melakukan pembayaran, serta melihat riwayat pesanan.

Program menerapkan konsep Pemrograman Berorientasi Objek (OOP) seperti class, object, constructor, encapsulation, inheritance, polymorphism, dan ArrayList.

🔹 **Fitur Utama:**
- Melihat daftar buket
- Memesan buket
- Membuat buket custom
- Melakukan pembayaran dan pembatalan
- Melihat riwayat pesanan
